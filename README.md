# PC-Database-2.0
This is a program made for saving data about numerous computers and their specifications.
I made this program, because I have so many computers that I am working on, that it had became quite difficult to remember everithyng about every computer.
Program is in it's early stages, but for now it meets my requirements.

----------
Instalation:
As the program does not come with the setup program, you just need to extract the Zip file to any folder (preferably to c:\Program Files), and then you have to make a shortcut of PC Database 2.0.exe on the desktop.
----------
Use:
The program itself does not need an explanation on how to use it.
You just click on Add computer, type in all the details, click save, and the computer has been added.
If you double click on the computer in the list view, you will see all the details about it.
You can easily edit an already existing computer by clicking on Edit computer button.
And when the list of computers becomes too big for you to be able to find it, I also added the search function, to make searching for computers even easier.
